# 0day 价值评估与变现渠道（用户战略咨询参考，2026-08）

用户问过"哪些 0day 有价值 / 普华、芋道、vCenter 算吗 / 能换钱吗"。回答框架：

## 价值四维度
1. 部署量 —— 能打多少目标（"一套打一片" vs "打一个算一个"）
2. 资产位置 —— 边界设备/核心枢纽 > 普通业务系统（决定打下来能拿什么）
3. 利用稳定性 —— 免杀难度、WAF 对抗、成功率
4. 变现渠道 —— 有无官方 SRC / CNVD 收录价值 / 厂商应急收购意愿

## 产品类别速评（用户点名过）
- **vCenter/虚拟化平台**：价值天花板。内网核心枢纽（拿下=控制集群=所有虚拟机），
  部署量极大；虚拟化 0day 是 ZDI/Zerodium 明确目标类型，CNVD 收录级别高。HW+变现两头硬。
  历史参照：CVE-2021-21972 公开前被 APT 武器化
- **开源框架（芋道/RuoYi 系）**：HW 刷分神器（部署量大、一套打一片），但无官方 SRC
  赏金、资产多为中小系统 → 变现一般。当"日常弹药"挖，不当生意
- **小众信创（普华等）**：信创专项场景有价值（HW 信创重点），但部署量被麒麟/UOS 挤占，
  0day 通用性差，变现基本无。顺手攒着用

## 合法变现渠道（天花板有限，实话实说）
- 大厂 SRC（阿里/腾讯/字节/华为）：RCE 级别几千~十几万
- CNVD/CNNVD 收录：证书+奖金，高危几千~几万
- 补天/漏洞盒子众测项目
- 厂商应急响应收购（深信服/奇安信收自家产品 0day）
- ZDI/Zerodium 类境外合法收购：价高但主要收浏览器/OS/虚拟化，流程复杂、涉密风险高
- 红线：地下 0day 交易（暗网/灰产）违法；HW 期间卖情报给对抗方是大忌，不碰

## 对用户的核心建议
- 0day 真实价值在 HW 的"先手优势"——公开 CVE 大家都会打，0day 才拉开差距
- 方向排序：边界/虚拟化/网关设备（vCenter 类）> 开源框架（广撒网）> 小众信创
- 公开 POC 库是"及格线"，冲高分要攒自己的未公开利用链
