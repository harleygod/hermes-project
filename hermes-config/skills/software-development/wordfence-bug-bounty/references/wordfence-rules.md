# Wordfence Bug Bounty 官方规则提炼（2026-08 用户提供）

## 范围（Scope）

- 任何估计活跃安装量 < 1000 的软件：**必须**在 wordpress.org 仓库中才在范围内（premium 排除）
- 安装量 ≥ 1000 的 premium 插件/主题：免费版在范围内则 premium 也在范围，但赏金按 premium 安装量计算
- premium 无公开安装数：按销量 1:1 估算；无销量信息用内部指标估算
- 捆绑插件不自动共享主插件安装量

## 赏金评估因素（影响金额）

| 因素 | 影响 |
|------|------|
| 利用前提（软件设置/服务器配置） | 减分（如"需勾选某设置"） |
| 自动化利用的容易度/可复现性 | 易自动化 → 加分 |
| 需用户交互（主动或被动） | 减分 |
| 对站点 CIA 的整体影响 | 影响大 → 加分 |
| 依赖同一软件之外的另一漏洞 | 赏金至少减半 |

## 类型特殊规则

- **PHP Object Injection**：有"新的已文档化可用 gadget"（插件内或 WP Core 当前版本内）+ 报告中演示利用 → 最高级别；否则降级（无 gadget = 无实际影响；gadget 已知 = 已被演示过）
- **Basic Information Disclosure**：低价值（如邮箱泄露、日志暴露、phpinfo）

## 月度冲刺奖金（Monthly Bug Detector Streak Bonus）

- 不累计，按当月最高档
- Apprentice（1-10 个提交/月）：5 个有效 → $35；10 个 → $75
- Trainee（11-30）：20 个 → $200；30 个 → $300
- Professional（31+）：仅 High-Threat 清单漏洞计入；40 个（含 10 High-Threat）→ $600；50（含 20）→ $1000；60（含 30）→ $1200
- 质量控制：
  - Out of Scope 提交不计入冲刺
  - **同 CWE + 认证级别组合每年最多 5 个计入冲刺**（超额仍可正常得赏金但不涨冲刺）
- 付款：每月 1 号和 15 号

## 策略推论

1. 默认配置可利用 > 配置依赖（配置依赖直接减分）
2. RCE/SQLi/任意文件操作/提权（High-Threat）优先于信息泄露
3. 组合链必须全在同一插件内，否则赏金减半
4. 提交类型要多样化（CWE × 认证级别），避免同质化
5. 最低 $5，低价值洞也可交但别当主攻
