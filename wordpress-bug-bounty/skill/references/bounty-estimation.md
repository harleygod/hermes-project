# Wordfence / HackerOne 赏金预估体系（2026-08 沉淀）

## 核心真相：金额不公开，只有区间
- Wordfence **不公开单个漏洞的赏金金额**——没有"每个 CVE 多少钱"的表。提交后由审稿人内部评估，只在支付时告知数字。
- 用户问"某漏洞多少钱"时：给**档位 × 类型**的预估区间，并说明来源是公开规律不是官方报价。
- 公开可查的只有：CVSS 评级（CRITICAL/HIGH/MEDIUM）和安装量档位——都不是金额。

## Wordfence 档位表（公开规律，按安装量）
```
安装量        低值类型(XSS/CSRF/Basic Info)   High-Threat(RCE/SQLi/提权/任意文件)
0-100         $5-25                          $25-100
100-1k        $25-100                        $100-500
1k-10k        $100-500                       $500-1,500
10k-100k      $300-1,500                     $1,500-5,000
100k+         $500-3,000                     $5,000-10,000
```
- 类型权重决定区间内高低：反射 XSS 永远最低档；未认证 RCE + 默认配置 + 零交互 = 区间高位。
- 三步预估法：① 插件/主题还是 Core？（Core 直接排除，Wordfence 只收第三方插件/主题）② 安装量落哪档？③ 类型权重。
- 实战估算例：sliced-invoices（5000 装，未认证 P1 信息泄露）= 1k-10k 档 + 中危 ≈ $100-300；同安装量未认证 RCE ≈ $500-1,500。

## WordPress Core 漏洞：走 HackerOne，不在 Wordfence 范围
- Wordfence Bug Bounty **明确不收 Core**——Core 漏洞由 WordPress 官方 HackerOne 计划处理（Wordfence 只做披露分析，不付钱）。
- HackerOne WordPress 计划（公开运行多年）：
  - 最低 $100（任何有效漏洞）
  - 严重（未认证 RCE/核心提权/数据库接管）：最高 **$12,500**
  - 高危（认证 RCE/SQLi/大规模泄露）：$1,000-5,000
  - 中危（XSS/CSRF 变体/权限提升）：$500-1,500
  - 低危（用户枚举/信息泄露）：$100-500
- 官方页面需登录才能看 Bounty 字段：https://hackerone.com/wordpress（权威来源；给用户链接让其自行核实，金额以页面为准）
- Core 单价高一个量级但竞争也高一个量级（全球在盯、重复率极高）——对"冷门插件甜区"策略无影响。

## 常见误判（用户会问的点）
- 用户看到 Core CVE（如 CVE-2026-64638 WP 7.0.2 预认证反射 XSS）以为能交 → 澄清：Core 不在 Wordfence 范围。
- 用户以为"披露页有金额" → 澄清：Threat Intel 页只有 CVSS/评级，没有金额。
- 搜索引擎片段里的金额（如搜索词回显 "$12,500"）不是来源证据——确认金额必须打开官方页面。
